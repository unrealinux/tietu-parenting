## 一、本期 6 个赛道（只从这 6 个里选，不要跨赛道）

长期赛道选择遵循 3 个原则：**内容可成为系列 / 用户能产生情绪和互动 / 素材可持续找到**。

## 二、找对标的三个方法

1. **对标库横向看**（本项目 100 个对标库，仅向本期学员开放，勿外传、勿直接搬运）
   每个候选方向先留 3–5 条，比较人群、场景、情绪、图片调性、评论区。
2. **继续下拉，进入「更多相关贴图」和话题页**
   滑到内容末尾 → 看相关推荐 → 连续看 3–5 条，判断是否同一人群 / 同一情绪 / 同一调性。
   结果开始重复时换维度：同赛道换人群、同人群换场景。
3. **比较库内相邻案例的标题结构**
   不只收藏原句，要比较同一结构的不同写法，例如「你们那边叫什么」「这种东西现在很少见了」「刚从某地回来，最想提醒的是……」

补充：搜一搜关键词 + 标题反搜。把高互动标题放回搜一搜，比较 3–5 条同主题内容看别人怎么调人群、场景、标题、首图。

### 判断某个方向值不值得继续观察
- 同一方向在不同入口都能反复看到，而不只出现在自己的推荐页
- 近期仍有作者持续更新，不是只剩很久以前的一条爆款
- 评论区真的围绕主题回答、怀旧、站队、补经历或给建议
- 标题、情绪、图片调性的共同点能被说清，而不是只觉得「看起来很火」
- 自己能够持续找到合规素材，并延展出相邻主题

**不要用一条爆款替平台下结论。**

## 三、图片三条路线（同一个赛道会随题目切换）

1. 有自有或授权原图 → 优先用真实源图
2. 没有可用原图但可以做画面示意 → 生成纪实无字底图
3. 只有图片必须靠一句话才能成立 → 才叠加标题或少量标注

素材来源：自己拍摄 / 正规图库（确认授权与商用边界）/ 跨平台案例（只找题材、构图、标题、图片角色，不能原样搬运）。

## 四、发布路径（官方口径）

- 推荐：**公众号助手 App** 注册 + 实名 + 发布（认准开发者「深圳市腾讯计算机系统有限公司」）
- 备选：微信公众平台官网
- **微信内置「公众号」入口只用于注册，不要从这里直接发布贴图内容**
  → 否则无法确保内容进入标准发布链路，影响流量主收益

### 电脑端
登录微信公众平台 → 草稿箱 → 点右侧「+」→ 选择贴图 → 上传图片 → 填标题正文 → 预览 → 发布

### 手机端
公众号助手 → 新的创作 → 选择贴图 → 上传调整顺序 → 填标题正文 → 预览 → 发布

## 五、昵称 / 头像 / 简介

- **昵称**：一眼看懂大致方向，可保留人格感但带赛道或场景线索。
  「某某职场避坑」「某某养花笔记」优于「某某生活」「某某日记」。
- **头像**：清晰简单，与赛道气质一致。不要模糊图、复杂文字、无关表情包。
- **简介**：一句话说清「写给谁 + 持续提供什么」，例如「写给普通打工人的职场避坑贴图，持续记录真实场景和实用提醒」。
- **自动回复**：只说明持续更新什么。主线阶段不放销售和外部联系方式。

## 六、多账号矩阵（单号跑通前不要做）

- 亲友主体需**本人合规注册并持续知情**，不是「借身份证绕过限制」。开始前写清账号归属、管理员、登录恢复、收益结算、税务责任、退出方式。
- 一机一号一卡：专用设备 + 长期使用的手机号 + 固定管理员。
- 设备、登录、网络保持稳定。**不要用代理、虚拟定位、频繁换 IP 去规避审核**。
- 一个身份证只能认证一个公众号；矩阵扩容要靠家人实名或独立贴图号，具体以平台当前规则为准。

## 七、内容制作中的常见卡点

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 没有「注册」按钮 | 版本未更新 / 已有可管理公众号 / 暂不符合注册条件 | 升级 App、重新登录；仍无入口走官网 |
| 提示达到注册上限 | 本人身份已注册过个人公众号 | 先找回并管理已有账号，不要用他人身份绕过 |
| 名称无法使用 | 重复、含限制词、易误认官方 | 用备选名，避免「官方、第一、唯一」 |
| 收不到验证码 | 网络、短信拦截、频繁请求 | 检查拦截记录，等倒计时结束后再试 |

## 八、流量主安全红线

**不要制造广告点击和虚假数据。** 不要批量点赞、批量收藏、批量下载，不要使用自动采集或模拟互动工具。

## 九、数据复盘的记录表（每条内容至少留这几项）

赛道与细分方向 / 素材来源 / 选题与标题结构 / 阅读与推荐变化 / 评论数量与内容 / 转发与收藏 / 人工修改记录 / 下一条动作

- 未开通流量主：先记录发布时间、主题、阅读量、流量来源、评论内容
- 已开通流量主：再看广告曝光量、收入、eCPM
  - 广告曝光量 = 广告实际展示次数
  - eCPM = 每千次广告展示的有效收入水平，随广告需求、用户和时间变化，**不是账号固定单价，也不能单独代表内容好坏**
- 「进池」是运营者说法，不是后台开关，也没有固定阅读量门槛。实用判断：**流量来源中出现推荐、搜索等非订阅用户入口，且不只发生在一条内容上。**
- 打开率 = 打开量 ÷ 曝光量。不要套用网上的固定优秀标准，跟自己账号同类型、相近发布时间的内容比。
